How the IMMS → MCS link works
1. User clicks "MAINTENANCE SYSTEM ↗" in IMMS
2. IMMS reads localStorage.token + user from AuthContext
3. Builds URL: http://localhost:3003#token=<jwt>&user=<btoa(user)>
4. Opens in new tab — MCS AuthContext auto-consumes fragment, lands on /calls
5. REACT_APP_MCS_URL in IMMS .env controls the MCS base URL
MCS Admin nav — visibility rule
Admin item only renders when user?.role === 'admin'. Other MCS roles (tech, operator, purchasing) don't see it.
