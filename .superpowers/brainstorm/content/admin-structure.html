Badge & Reader Management — where does it live?

Two options for how to organize this in MCS. Both are admin-only.

A

Inside Admin — tabbed page (recommended)

Admin page has two tabs: Badges (register operators & technicians) and Readers (register badge readers at machines). One nav item, one place for all admin tasks. Easy to add more tabs later (e.g. machine config).

MCS Nav
📋 Call History
📊 Live Board ↗
📈 Analytics
⚙️ Admin  ADMIN
/admin → tabs: [ Badges | Readers ]
B

Separate "Badges" nav item

Badges & Readers get their own top-level nav entry alongside Call History, Live Board, Analytics. Admin page stays separate (or doesn't exist yet). More visible, but adds clutter to the nav for a task most users never touch.

MCS Nav
📋 Call History
📊 Live Board ↗
📈 Analytics
🪪 Badges  ADMIN
/badges → tabs: [ Badges | Readers ]

I recommend A — keeps the nav clean and Admin becomes the single home for all setup tasks. Badges and Readers are already a natural pair (you register a reader, then register the badges that use it).
